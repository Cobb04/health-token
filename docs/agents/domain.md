# Domain Docs

This repository uses a single domain context.

## Before exploring

- Read `CONTEXT.md` at the repository root when it exists.
- Read relevant architectural decisions under `docs/adr/` when they exist.
- If either location does not yet exist, proceed without flagging its absence.

## Vocabulary

Use the domain terms defined in `CONTEXT.md` consistently in product specifications, issues, tests, and code. If a required concept is missing or overloaded, resolve it through domain modeling rather than silently introducing a synonym.

## Architectural decisions

Surface any conflict with an existing ADR explicitly. Do not silently override a recorded decision.
