# Issue tracker: GitHub

Issues and PRDs for this repository live as GitHub Issues. Use the `gh` CLI for all operations.

## Conventions

- Create an issue with `gh issue create`.
- Read an issue and its discussion with `gh issue view <number> --comments`.
- List issues with `gh issue list`, including labels and comments when relevant.
- Comment with `gh issue comment <number>`.
- Apply or remove labels with `gh issue edit <number>`.
- Close completed work with `gh issue close <number>` and a concise completion comment.

Infer the repository from the configured Git remote when operating inside this clone.

## Skill terminology

- When a skill says “publish to the issue tracker,” create a GitHub Issue.
- When a skill says “fetch the relevant ticket,” read the corresponding GitHub Issue and its comments.
